The Cafe "Happy Hour" Loyalty Billing System

Story & Business Scenario

Maya owns a bustling neighborhood café called The Daily Grind. To attract more customers and reward regular visitors, she wants to install a smart point-of-sale system. The system automatically calculates final bill discounts based on a customer's loyalty tier, whether it is currently "Happy Hour", and the total bill amount.

Business Rules & Logic Requirements:

VIP Members

    >Get 15% discount standard.
    >During Happy Hour: get extra 10% off (total 25% discount).
Regular Members

    >Bill > $20: get 10% discount.
    >Happy Hour AND Bill > $20: get 15% discount.
    >Bill ≤ $20: No discount (0%).
Guest Customers

    >No percentage discount.
    >If Happy Hour AND Bill > $50: flat $5.00 off.

FUNCTION calculate_cafe_bill(membership_type, bill_amount, is_happy_hour):
    SET discount_rate = 0.0
    SET flat_discount = 0.0

    IF membership_type IS EQUAL TO "VIP" THEN
        IF is_happy_hour IS TRUE THEN
            SET discount_rate = 0.25
        ELSE
            SET discount_rate = 0.15
        END IF

    ELSE IF membership_type IS EQUAL TO "Regular" THEN
        IF bill_amount > 20 THEN
            IF is_happy_hour IS TRUE THEN
                SET discount_rate = 0.15
            ELSE
                SET discount_rate = 0.10
            END IF
        ELSE
            SET discount_rate = 0.0
        END IF

    ELSE IF membership_type IS EQUAL TO "Guest" THEN
        IF is_happy_hour IS TRUE AND bill_amount > 50 THEN
            SET flat_discount = 5.0
        END IF
    END IF

    SET final_bill = (bill_amount * (1.0 - discount_rate)) - flat_discount
    RETURN ROUND(final_bill, 2)
END FUNCTION
def calculate_cafe_bill(membership_type, bill_amount, is_happy_hour):
    discount_rate = 0.0
    flat_discount = 0.0

    if membership_type == "VIP":
        if is_happy_hour:
            discount_rate = 0.25
        else:
            discount_rate = 0.15

    elif membership_type == "Regular":

                discount_rate = 0.15

                discount_rate = 0.10
        else:
            discount_rate = 0.0

    return round(final_bill, 2)

GizmoHub Smart Shipping Engine

Story & Business Scenario

Alex manages an e-commerce platform called GizmoHub. Shipping rates are getting complicated because foreign deliveries, heavy packages, express upgrades, and free-shipping order thresholds all interact differently. Alex needs an automated decision tree to calculate shipping costs accurately for every checkout order.

Business Rules & Logic Requirements:

Domestic Orders

    >Order Total ≥ $100: Free Base Shipping ($0).
    >Order Total < $100:

      >Weight ≤ 2 kg: $5.00 base fee.
      >Weight > 2 kg: $5.00 + $2.00 per extra kg.

    >If Express: Add +$8.00 fee (applies even on free shipping).
International Orders

    >Weight ≤ 5 kg: $25.00 base fee.
    >Weight > 5 kg: $25.00 + $5.00 per extra kg above 5 kg.
    >If Express: Add extra +$20.00 handling fee.
    >No standard free shipping for international orders.

FUNCTION calculate_shipping_fee(destination, weight, is_express, order_total):
    SET shipping_fee = 0.0

    IF destination IS EQUAL TO "Domestic" THEN
        IF order_total >= 100 THEN
            SET shipping_fee = 0.0
        ELSE
            IF weight <= 2 THEN
                SET shipping_fee = 5.0
            ELSE
                SET extra_weight = weight - 2
                SET shipping_fee = 5.0 + (extra_weight * 2.0)
            END IF
        END IF

        IF is_express IS TRUE THEN
            SET shipping_fee = shipping_fee + 8.0
        END IF

    ELSE IF destination IS EQUAL TO "International" THEN
        IF weight <= 5 THEN
            SET shipping_fee = 25.0
        ELSE
            SET extra_weight = weight - 5
            SET shipping_fee = 25.0 + (extra_weight * 5.0)
        END IF

        IF is_express IS TRUE THEN
            SET shipping_fee = shipping_fee + 20.0
        END IF
    END IF

    RETURN ROUND(shipping_fee, 2)
END FUNCTION
def calculate_shipping_fee(destination, weight, is_express, order_total):
    shipping_fee = 0.0

    if destination == "Domestic":
        if order_total >= 100.0:

        else:
            if weight <= 2.0:

                extra_weight = weight - 2.0

        if is_express:
            shipping_fee += 8.0

    elif destination == "International":
        if weight <= 5.0:
            shipping_fee = 25.0
        else:
            extra_weight = weight - 5.0
            shipping_fee = 25.0 + (extra_weight * 5.0)

        if is_express:
            shipping_fee += 20.0

    return round(shipping_fee, 2)

CityCab Dynamic Fare & Weather Surcharge

Story & Business Scenario

A ride-hailing company, CityCab, needs to update its ride estimation logic. Depending on peak traffic hours and weather conditions (rain or snow), driver availability drops drastically. The system must automatically calculate the total ride fare accounting for distance rate tiers, weather, weekend multipliers, and long-distance incentives.

Business Rules & Logic Steps:

1. Base & Weather Rate

Base Fare: $3.00 flat.
Clear: $1.50/mile
Rainy: $2.00/mile
Snowy: $2.50/mile

2. Peak Surge Multiplier

Peak + Weekday: 1.4x on subtotal.
Peak + Weekend: 1.2x on subtotal.
Off-Peak: 1.0x (No multiplier).

3. Long Distance Discount

If distance > 20 miles:
Deduct flat -$5.00 off final price.

FUNCTION calculate_taxi_fare(distance_miles, time_period, weather, is_weekend):
    SET base_fare = 3.0

    // 1. Determine rate per mile based on weather
    IF weather IS EQUAL TO "Rainy" THEN
        SET rate_per_mile = 2.0
    ELSE IF weather IS EQUAL TO "Snowy" THEN
        SET rate_per_mile = 2.5
    ELSE
        SET rate_per_mile = 1.5
    END IF

    SET subtotal = base_fare + (distance_miles * rate_per_mile)

    // 2. Apply surge multiplier for peak hours
    IF time_period IS EQUAL TO "Peak" THEN
        IF is_weekend IS FALSE THEN
            SET subtotal = subtotal * 1.4
        ELSE
            SET subtotal = subtotal * 1.2
        END IF
    END IF

    // 3. Apply long-distance discount
    IF distance_miles > 20 THEN
        SET subtotal = subtotal - 5.0
    END IF

    RETURN ROUND(subtotal, 2)
END FUNCTION
def calculate_taxi_fare(distance_miles, time_period, weather, is_weekend):
    base_fare = 3.0

    # 1. Determine rate per mile based on weather
    if weather == "Rainy":
        rate_per_mile = 2.0
    elif weather == "Snowy":
        rate_per_mile = 2.5
    else:
        rate_per_mile = 1.5

    subtotal = base_fare + (distance_miles * rate_per_mile)

    # 2. Apply surge multiplier for peak hours
    if time_period == "Peak":
        if not is_weekend:
            subtotal *= 1.4
        else:
            subtotal *= 1.2

    # 3. Apply long-distance discount
    if distance_miles > 20.0:
        subtotal -= 5.0

    return round(subtotal, 2)
double calculateTaxiFare(double distanceMiles, std::string timePeriod, std::string weather, bool isWeekend) {
    double baseFare = 3.0;
    double ratePerMile = 1.5;

    if (weather == "Rainy") {
        ratePerMile = 2.0;
    } else if (weather == "Snowy") {
        ratePerMile = 2.5;
    }

    double subtotal = baseFare + (distanceMiles * ratePerMile);

    if (timePeriod == "Peak") {
        subtotal *= (!isWeekend) ? 1.4 : 1.2;
    }

    if (distanceMiles > 20.0) {
        subtotal -= 5.0;
    }

    return subtotal;
}
